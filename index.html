A FEW THINGS WORTH KNOWING

Good questions.
Clear answers.

Early software, honest boundaries.
Here’s what to expect from the beta.

What is a scenario?+

A scenario is the context in which a pipeline would be created: a push, merge request, schedule, or manual run. The same configuration can include different jobs in each context. You choose an event, variables and changed files to explore the supported rules.

Does Pipeline Atlas run my jobs?+

No. It reads and analyzes pipeline configuration; it never runs repository scripts to discover what they do. An included job is eligible to run, not a promise that its commands or tests will succeed.

Can I use private repositories and self-managed GitLab?+

Yes. Connect GitHub, GitLab.com or a self-managed GitLab instance using your own access. Credentials stay in your Mac’s Keychain. Access to includes and other repositories still depends on your permissions. IT-approved VPN, explicit proxy, and company certificate settings are supported. Real-world GitLab pilot validation is ongoing.

What about parent and child pipelines?+

Explore supported static GitLab child and multi-project pipelines, plus GitHub reusable workflows, including accessible cross-repository calls. Generated GitLab child configuration needs a supplied artifact. Unavailable repositories and unsupported behavior are shown as incomplete analysis.

Can it catch every broken pipeline?+

No. It helps find configuration problems, excluded dependencies and supported rule changes. Runtime values, dynamic configuration and unsupported expressions can remain unknown. It cannot predict failures in application code, shell scripts, runners or external services.

What will it cost?+

The planned US Mac App Store price is US$19.99 upfront. There is no subscription, in-app purchase, or license key. Buyers get the full app and future updates to this App Store listing. Sales are not open yet.

Which Macs are supported?+

The first Mac App Store edition targets Apple silicon Macs (M1 or newer) running macOS 14 or later. Intel, Windows, and Linux desktop editions are not planned for this first release.

How do updates work?+

Apple delivers updates through the Mac App Store. Future updates to this listing are included with your purchase. Keep a backup of important reports when testing beta software.
